# 生活数学与逻辑思考 36 课

这是一套面向 8 岁与 11 岁学生的混龄生活数学公开课。课程从早餐、购物、地图、饮料、排队、天气和旅行等真实问题出发，引导学生经历“理解情境、建立表示、推理计算、检查答案、迁移应用”的完整过程。

课程已经整理为 36 节网页版，并提供可编辑的教师用书。任何人都可以阅读、使用、提出纠错或改进建议；进入官方版本的修改仍需由维护者审核。

## 直接使用

- [网页版课程](https://yunfeilab.com/zh/courses/kids/)
- [下载可编辑教师用书](https://yunfeilab.com/downloads/life-math-and-logical-thinking-36-teacher-guide.docx)
- [查看 36 节课程源文件](../../site/src/content/courses/zh/math/)
- [查看六个单元插图](../../site/public/images/courses/math/)

教师用书共 99 页，包含课程总表、42 分钟课堂流程、分龄任务、追问、练习答案、课后实践、达标标准、任务卡和评价表。公开副本已移除个人及设备元数据。

## 课程索引

| 单元 | 课次 | 主题范围 | 主要能力 |
| --- | --- | --- | --- |
| 第一单元 数量与估算 | 01–06 | 早餐、找零、食谱、行李、等车、温度 | 估算、四则运算、单位、时间与数轴 |
| 第二单元 测量与空间 | 07–12 | 地图、围栏、地板、水壶、方向、房间 | 长度、周长、面积、容量、角度与比例尺 |
| 第三单元 比例与变化 | 13–18 | 披萨、果汁、折扣、骑车、打车、电量 | 分数、比、百分数、速度、分段计费与变化率 |
| 第四单元 条件与推理 | 19–24 | 分类、条件、真假、排程、路径、策略 | 集合、命题、排除、约束、最短路径与逆向推理 |
| 第五单元 数据与概率 | 25–30 | 天气、调查、平均、图表、抽签、风险 | 数据记录、统计量、图表辨析、概率与决策 |
| 第六单元 规划与决策 | 31–36 | 预算、菜单、野餐、排队、撤离、旅行 | 多条件整合、取整、模型、冗余与方案表达 |

网页版会根据课程文件自动生成完整目录和前后课导航，不另行维护一份容易过期的 36 条链接表。

## 怎样提出改进

1. 小纠错或建议：提交 [Issue](https://github.com/zyfjazz-ship-it/yunfei-evolution/issues/new/choose)，写清课次、原文位置、问题和建议。
2. 已经改好内容：Fork 仓库，新建分支后提交 Pull Request。
3. 课程结构、教学目标或大段内容调整：先开 Issue 说明原因、证据和影响范围，讨论后再提交修改。

详细流程见 [CONTRIBUTING.md](./CONTRIBUTING.md)。公开 Pull Request 是“请求维护者审阅并合并”，不会绕过审核直接修改官方主分支。
