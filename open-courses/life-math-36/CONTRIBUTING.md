# 参与改进生活数学与逻辑思考 36 课

欢迎教师、家长、学生和内容创作者提出纠错、补充案例、改进活动设计或增强无障碍阅读。所有贡献都应帮助读者更准确、更容易地理解和使用课程。

## 先判断用 Issue 还是 Pull Request

- 用 Issue：错别字、答案疑问、表达不清、教学建议、新活动想法、课程结构讨论。
- 用 Pull Request：你已经完成了明确、可审阅的修改。
- 先 Issue 后 Pull Request：新增或删除课程、大范围重写、改变年龄分层、调整核心教学目标、引入外部图片或大量第三方内容。

## 提交 Issue

请尽量写清：

1. 课次与标题。
2. 网页链接或文件路径。
3. 原文位置和当前问题。
4. 建议修改内容及理由。
5. 如涉及事实、数据或图片，附可靠来源及许可信息。

不要在公开 Issue 中上传学生姓名、照片、联系方式、成绩或其他个人信息。

## 提交 Pull Request

1. Fork 本仓库并从最新 `main` 新建分支。
2. 一次 Pull Request 只解决一个清晰问题。
3. 保留课程现有结构和语气，不随意混入经济课、历史课或其他课程内容。
4. 修改练习、答案或公式时，重新独立计算并说明验证方式。
5. 新增图片前确认你拥有授权，并在说明中写明作者、来源链接和许可。
6. 在 Pull Request 中说明修改了什么、为什么改、如何检查，以及影响哪些课。

课程正文位于 `site/src/content/courses/zh/math/`。教师用书是完整可编辑版本；若修改同时影响网页版和教师用书，请在 Issue 中说明同步方案，避免两个版本长期不一致。

## 审核标准

维护者会重点检查：

- 数学和答案是否准确。
- 活动是否适合目标年龄，是否能在真实课堂中执行。
- 8 岁与 11 岁任务是否有合理差异，但仍能共同讨论。
- 课程是否从生活问题出发，并要求学生解释和检验。
- 新增材料的版权和引用是否清楚。
- 是否泄露未成年人的个人信息。

提交 Pull Request 不代表修改会自动进入官方版本。维护者可以要求调整、暂缓或拒绝合并；只有审核并合并后的内容才属于官方主分支。

## 贡献者授权

提交课程文字、练习或原创插图，即表示你有权提交这些内容，并同意你的贡献按本课程当时采用的内容许可发布。不要提交你无权再授权的教材扫描、付费题库、网络图片或大段转载内容。

## 行为原则

围绕内容和证据讨论，不攻击个人；尊重不同教学环境；指出问题时尽量给出可验证的理由或替代方案。涉及未成年人时，以隐私和安全为先。
