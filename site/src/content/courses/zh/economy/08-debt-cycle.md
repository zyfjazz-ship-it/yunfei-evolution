## 本节问题

为什么经济最危险的时候，往往不是所有人都悲观的时候，而是房价上涨、银行愿意放贷、企业不断扩张、人人相信明天会更好的时候？

因为债务有一个特殊作用：**它能把未来的购买力搬到今天。**

这会让今天更繁荣，却也会让未来多出一笔必须偿还的账。只要收入增长得比债务快，借钱可以帮助生产；当债务增长长期快于收入，繁荣就可能逐渐变成一套依赖继续借钱才能维持的结构。

## 从一套 500 万元的房子开始

假设一个家庭有 150 万元存款，年收入 60 万元。他们贷款 350 万元，买下一套价值 500 万元的房子。

交易完成的一刻，发生了三件事：

1. 家庭提前使用了未来二十多年的一部分收入；
2. 卖房者今天就得到了现金；
3. 银行得到了一项会持续产生利息的贷款资产。

如果房价第二年涨到 600 万元，这个家庭会觉得自己的财富增加了。银行也会觉得抵押物更安全，更愿意继续放贷。周围的人看到房价上涨，又担心自己错过机会，于是更多人借钱买房。

这时，房价上涨不只是一个结果，它开始变成下一轮贷款的原因。

> 贷款增加购买力，购买力推高资产，资产上涨改善抵押品，抵押品又支持更多贷款。

这就是债务周期最重要的正反馈。

## 繁荣的六个台阶

### 1. 利率较低，借钱变得容易

月供下降，企业项目更容易达到预期回报，家庭和企业都愿意增加负债。

### 2. 信用创造了新的支出

贷款不是把一笔旧钱简单地从甲交给乙。银行放贷会同时形成存款，社会当期可以使用的购买力因此增加。

### 3. 支出变成别人的收入

家庭买房，钱进入开发商和卖房者账户；企业扩建，钱成为建筑、设备和员工的收入。经济活动加速，就业和利润改善。

### 4. 资产价格上涨

当新增信用大量进入房产、股票或土地，价格上涨会让借款人看起来更富，银行的抵押品也看起来更安全。

### 5. 风险被上涨掩盖

只要资产还能用更高价格卖给下一位买家，坏项目也可能暂时不暴露。人们会把“价格一直上涨”误认为“风险已经消失”。

### 6. 债务增长超过收入

真正的转折点不是债务数字很大，而是偿债所需的现金流开始超过收入能够承受的范围。

## 判断风险，不能只看欠了多少钱

两个人都欠 300 万元，风险可能完全不同。

一个人年收入 150 万元，贷款利率固定，还有充足现金；另一个人年收入 30 万元，贷款利率会浮动，收入又依赖房价继续上涨。两人的债务总额相同，承受能力却完全不同。

判断债务至少要看四件事：

| 问题 | 真正要看的东西 |
| --- | --- |
| 欠了多少？ | 债务相对于收入和资产的比例 |
| 每期要还多少？ | 利息加本金占现金流的比例 |
| 用什么货币借？ | 收入货币与债务货币是否一致 |
| 什么时候到期？ | 短期是否必须再融资 |

上节课学过汇率后，第四层风险就更容易理解：一家收入主要是人民币的企业，如果借了大量美元债，美元升值会让它的债务在人民币计价下突然变重。

## 周期为什么会反转

周期不一定要等到所有人破产才反转。它只需要“新增贷款不再继续加速”。

可能的触发点包括：

- 央行为抑制通胀而加息；
- 银行发现坏账，收紧贷款条件；
- 企业利润下降，家庭收入减少；
- 房价停止上涨，抵押品价值下降；
- 外币升值，外债负担上升。

当房价从 600 万元跌回 450 万元，原来的贷款不会跟着减少。家庭会削减消费来还债；银行担心抵押品不足，不愿新增贷款；买家减少又令房价继续下跌。

繁荣期的正反馈于是倒转：

**资产下跌 → 抵押品缩水 → 银行惜贷 → 支出下降 → 收入下降 → 违约增加 → 资产继续下跌。**

这叫去杠杆。它不只是“大家欠的钱太多”，而是整个系统同时从扩张转向收缩。

## 2008 年发生了什么

美国金融危机之前，低利率、宽松贷款和房价上涨相互强化。越来越多住房贷款被打包成证券，再出售给银行、基金和全球投资者。

表面上，风险被分散到了许多机构；实际上，很多机构都依赖同一个前提：美国房价不会大范围持续下跌。

当房价下降、贷款违约增加，问题沿着资产负债表传导：

1. 家庭无法偿还房贷；
2. 房贷证券价值下跌；
3. 持有这些证券的机构出现亏损；
4. 银行不知道交易对手损失多大，开始互不信任；
5. 信贷市场冻结，原本健康的企业也难以融资；
6. 金融问题转化为失业、消费下降和实体经济衰退。

危机的关键不是某一种证券名字有多复杂，而是许多人的资产，其实对应着另一些人的债务。一方无法付款，另一方的“财富”就会缩水。

## 为什么央行和政府要救

当所有人同时卖资产、存现金、减少支出时，个体行为可能是理性的，合在一起却会让社会收入继续下降。

政策通常分成四类：

1. **降息与提供流动性**：避免银行因为短期缺钱而倒下；
2. **银行注资或担保**：修复金融系统的资本和信任；
3. **财政支出与减税**：在私人部门缩减支出时托住总需求；
4. **重组债务**：延长期限、降低利率、减记部分无法偿还的债务。

但救援没有免费的选择。救得太少，可能出现连锁破产；救得太多，又可能鼓励市场相信风险最终由社会承担。政策真正困难的地方，是在阻止系统崩溃和避免奖励冒险之间寻找边界。

## 通胀为什么能减轻旧债，却不能解决一切

大多数债务以固定的货币数字写在合同里。如果工资和商品价格普遍上涨，而旧债金额不变，债务相对于名义收入会变轻。

但如果利率也随通胀上升、债务需要频繁再融资，借款人的利息负担可能反而增加。外币债务也不会因为本国通胀自动消失。

所以不能简单地说“印钱就能还债”。最终仍要看收入、利率、期限、币种和生产能力。

## 怎样判断自己身处周期的哪一段

不要只问“房价还会不会涨”，而要连续问五个问题：

1. 债务增长是否长期快于收入？
2. 资产上涨是否主要依赖新增贷款？
3. 借款人能否用正常经营收入还债？
4. 利率上升一点，现金流是否就会断裂？
5. 银行是在根据收入放贷，还是根据资产会继续上涨来放贷？

如果一个系统必须依赖更低的利率、更多的新贷款和更高的资产价格才能维持，它就不再只是享受繁荣，而是在积累脆弱性。

## 这一课学到了什么

债务本身不是坏事。能够提高生产率、产生未来收入的债务，可以把未来做大的蛋糕提前用于今天；只依赖资产继续上涨、却不能产生足够现金流的债务，则是在把未来的收入提前消耗。

债务周期的核心不是“借钱一定危险”，而是看清三个速度：**债务增长、收入增长和资产价格增长。** 当三者长期脱节，利率、银行、汇率与资产价格就会在某个时点一起反转。
