# 创建你的第一个AI网站——Hello World

## 本篇目标

完成本篇学习后，你将：

- 拥有自己的GitHub数字仓库；
- 学会让AI连接项目文件；
- 使用Codex创建第一个网站；
- 发布自己的第一个公开网页。

最终，你会看到一个属于自己的网址。

这代表：你已经完成从AI使用者到AI创造者的第一次转变。

## 为什么要做？

很多人认为：“现在有抖音、公众号、小红书，为什么还需要网站？”

平台当然重要，但平台属于平台。账号可能受到规则影响，而个人网站属于自己的数字空间。

未来，你的个人网站可以保存：

- 你的文章；
- 你的思想；
- 你的项目；
- 你的作品；
- 你的个人品牌。

对于一个希望长期发展的个人来说，网站不是一个技术产品，而是一块属于自己的数字土地。

## 开始前准备

开始前，请准备好：

- ChatGPT账号；
- GPT Work；
- Codex；
- GitHub账号；
- GitHub Desktop；
- 一台可以稳定上网的电脑。

不需要先学会写代码。你要做的是学会把目标讲清楚，并让AI协助完成。

## 操作步骤

### 第一步：注册GitHub，建立你的数字资产仓库

GitHub可以简单理解为你的数字资产仓库。它可以保存网站文件、文章内容和项目资料。

1. 打开 [github.com](https://github.com)。
2. 点击 `Sign up`（注册）。
3. 推荐使用Google账号登录，减少账号管理的复杂度。
4. 设置一个准备长期使用的用户名。它可能会成为你的数字身份。

完成后，确认自己可以登录GitHub主页。

### 第二步：开启GitHub安全验证

GitHub会保存你的数字资产，所以需要保护账号。

1. 在手机上安装 Google Authenticator（谷歌身份验证器）。
2. 进入GitHub的 `Settings`（设置）。
3. 打开 `Password and authentication`。
4. 开启 `Two-factor authentication`（双重身份验证）。
5. 选择 `Authenticator App`。
6. 使用手机上的身份验证器扫描页面二维码。
7. 输入手机生成的6位动态验证码。
8. 保存GitHub提供的恢复代码。手机丢失时，它可以帮助你找回账号。

### 第三步：连接ChatGPT Work和GitHub

连接以后，AI可以协助管理项目，例如创建网站、修改文件和更新内容。

1. 打开 ChatGPT Work。
2. 进入设置中的连接选项。
3. 选择 GitHub。
4. 按页面提示登录并确认授权。

如果连接暂时没有写入权限，也不用着急。你可以先使用GitHub Desktop手动同步文件，之后再处理授权问题。

### 第四步：让Codex创建第一个网站

现在开始第一次AI创造。

打开Codex，告诉它你的目标。例如：

> 我要创建一个个人网站，名字叫云非的进化论，用来发布博客、展示项目，请帮我建立基础结构。

为什么要这样说？因为AI需要理解目标、用途和未来方向。

比起只说“帮我做网站”，一段清楚的目标描述会让AI做得更贴近你的需要。

Codex可以帮助你：

- 创建项目文件；
- 生成网站结构；
- 编写基础页面；
- 检查问题。

### 第五步：使用GitHub Desktop上传网站

GitHub Desktop把原本复杂的操作变得更直观，不需要记住难懂的命令。

1. 打开 GitHub Desktop，并登录GitHub账号。
2. 选择 `File` → `Add Local Repository`。
3. 选择Codex创建的网站项目文件夹。
4. 点击 `Add Repository`。
5. 第一次保存时，在 `Summary` 中填写 `Initial website`。
6. 点击 `Commit to main`。
7. 点击 `Push origin` 或 `Publish branch`。

### 第六步：使用GitHub Pages发布网站

GitHub Pages可以免费把项目发布成网站。

1. 打开GitHub仓库。
2. 点击 `Settings`。
3. 进入 `Pages`。
4. 选择 `GitHub Actions`。
5. 等待自动部署完成。

成功后，GitHub会提供一个网站地址，通常类似：

```text
https://你的用户名.github.io/项目名/
```

打开这个网址，看到 `Hello World` 或你的网站首页时，你就拥有了第一个属于自己的公开网站。

## 完成标准

请逐项确认：

- 可以登录GitHub；
- 已开启双重身份验证并保存恢复代码；
- 电脑中有一个网站项目文件夹；
- GitHub仓库中能看到网站文件；
- GitHub Pages已经开启；
- 可以在浏览器中打开自己的网址。

做到这些，就说明你已经完成了第一次“想法 → AI协作 → 公开展示”。

## 常见问题

### 我不会代码怎么办？

不用担心。你的目标不是成为程序员，而是学会管理AI完成创造。

### 为什么Codex不能直接上传？

通常是权限问题。AI工具仍然需要安全授权。遇到这种情况，可以先使用GitHub Desktop手动同步。

### 以后每次更新网站都需要这么麻烦吗？

不需要。后续流程会越来越简单：你提出内容，Codex修改，GitHub同步，网站自动更新。
