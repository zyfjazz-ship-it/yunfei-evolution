# 中年 AI 再就业计划

一个普通人借助 AI 学习、实践并完成职业转型的长期公开记录。

## 项目愿景

这不是一套只讲概念的 AI 教程，而是一次真实、持续、可验证的职业转型实践。项目将完整记录学习过程、遇到的问题、实战作品和求职准备，为同样希望借助 AI 改变职业方向的人提供参考。

## 项目目标

- 建立可持续的 AI 学习方法。
- 掌握 Markdown、GitHub、Python 和大模型应用开发。
- 完成一组能够公开展示的 AI 实战项目。
- 将学习成果整理为可复用的中文教程。
- 形成作品集、技能地图和职业转型记录。

## 当前状态

- 项目阶段：基础建设
- 启动日期：2026-07-11
- 当前任务：完善项目规范并开始第一阶段学习

## 内容导航

- `logs/`：每日学习日志与阶段复盘
- `tutorials/`：经过实践验证的系统教程
- `projects/`：可运行、可展示的实战项目
- `docs/`：项目介绍、路线图与职业规划
- `resources/`：书籍、课程、工具和术语整理

## 90 天行动计划

项目分为五个阶段：

1. 建立学习、写作和版本管理基础。
2. 学习 Python 与大模型 API。
3. 实践知识库与工作流自动化。
4. 学习智能体并完成产品化应用。
5. 整理作品集并准备求职。

完整计划参见 [ROADMAP.md](ROADMAP.md)。

## 内容原则

- 真实记录成功、失败和未解决的问题。
- 教程必须经过实际操作和结果验证。
- 明确说明 AI 在内容创作和问题解决中的作用。
- 不提交密码、令牌、个人隐私或未获授权的资料。
- 重要结构调整与发布决策均先提出方案，再执行修改。
